
# OpenGL Window — CMake Starter Project

A minimal modern OpenGL 3.3 Core project using GLFW, GLAD, and GLM.

---

## Prerequisites

### Linux — Arch / Manjaro

```bash
sudo pacman -S mesa mesa-utils glfw glm cmake base-devel
```

> **GPU drivers:**
> - Intel: `mesa` is enough
> - AMD: add `vulkan-radeon`
> - NVIDIA: add `nvidia nvidia-utils`

Verify OpenGL is working:
```bash
glxinfo -B
```
You should see your GPU name, not `llvmpipe`.

---

### Linux — Ubuntu / Debian

```bash
sudo apt update
sudo apt install build-essential cmake libglfw3-dev libglm-dev mesa-utils
```

> **GPU drivers:**
> - Intel / AMD: Mesa is installed automatically as a dependency
> - NVIDIA: `sudo apt install nvidia-driver-xxx` (replace xxx with latest version from `ubuntu-drivers devices`)

Verify:
```bash
glxinfo -B
```

---

### Windows

Install the following:

| Tool | Download |
|---|---|
| CMake | https://cmake.org/download/ |
| MinGW-w64 (GCC) or MSVC | https://www.mingw-w64.org/ or Visual Studio |
| GLFW pre-compiled binaries | https://www.glfw.org/download.html |
| GLM (header-only) | https://github.com/g-truc/glm/releases |

> Alternatively use **vcpkg** to manage dependencies:
> ```powershell
> vcpkg install glfw3 glm
> ```

## GLAD — Download Manually (All Platforms)

GLAD is not installed via a package manager. Generate and download it from:

**https://glad.dav1d.de/**

Settings to select:
- **Language:** C/C++
- **Specification:** OpenGL
- **API gl:** 3.3
- **Profile:** Core
- Click **Generate** then download the zip

Extract the zip and place the files as follows:

- Copy `glad/include/glad/` → `include/glad/`
- Copy `glad/include/KHR/` → `include/KHR/`
- Copy `glad/src/glad.c` → `src/glad.c`

## Folder Structure

After cloning and adding GLAD, your project should look like this:

```
opengl-starter/
├── CMakeLists.txt
├── README.md
├── build.sh
├── run.sh
├── include/
│   ├── glad/
│   │   └── gl.h
│   └── KHR/
│       └── khrplatform.h
├── src/
│   ├── main.cpp
│   └── glad.c
└── build/          ← generated by cmake, do not touch
```

> The `include/glad/`, `include/KHR/`, and `src/glad.c` files are not included in this repo — you must download and place them yourself from the link above.

## Build & Run

### Linux / macOS

```bash
# Clone the repo
git clone https://github.com/yourusername/opengl-starter.git
cd opengl-starter

# Download and place GLAD files (see above)

# Build and run using scripts
chmod +x build.sh run.sh
./build.sh
./run.sh
```

Or manually:
```bash
mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Debug
ninja        # or: make -j$(nproc)
cd ..
./build/opengl-starter
```

### Windows (MinGW)

```powershell
git clone https://github.com/yourusername/opengl-starter.git
cd opengl-starter

# Download and place GLAD files (see above)

mkdir build && cd build
cmake .. -G "MinGW Makefiles"
mingw32-make

opengl-starter.exe
```

### Windows (MSVC / Visual Studio)

```powershell
mkdir build && cd build
cmake .. -G "Visual Studio 17 2022"
# Open the generated .sln file in Visual Studio and build from there
```

## Expected Output

A dark blue 800×600 window titled **"OpenGL Starter"** will appear.

The terminal will print:
```
OpenGL: 3.3.0 (or higher)
Renderer: <your GPU name>
```

Close the window or press `Ctrl+C` in terminal to exit.

## Troubleshooting

**Renderer shows `llvmpipe` instead of your GPU**
Software rendering is active — your GPU driver is not working. Reinstall your GPU drivers.

**`glxinfo` not found**
Install `mesa-utils` (Arch) or `mesa-utils` (Ubuntu).

**CMake can't find GLFW**
Make sure `libglfw3-dev` (Ubuntu) or `glfw` (Arch) is installed. On Windows, set `glfw3_DIR` in CMake to your GLFW install path.

**Black screen / crash on startup**
Make sure `include/glad/gl.h`, `include/KHR/khrplatform.h`, and `src/glad.c` are present and were generated with **OpenGL 3.3 Core** profile.
